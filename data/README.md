# Data

**What this public copy holds.** Only results we derived: model forecasts and scores, predictor importance, the fragility indices and the GARCH fits. The inputs are not: neither the downloaded datasets listed below nor the files built straight from them (the monthly panel, the point-in-time series, the S&P 500 events, CAPE, HHI and the volatility probabilities), since several are copyrighted by their source or licensed (CRSP via WRDS, Yahoo, Cboe, Moody's, Nasdaq, the University of Michigan). To rerun the analysis, download each file from the source given and save it under the path shown. The table describes the files as the team used them.

Every dataset in the repository, with where it came from. Files are kept exactly as downloaded; only the name changes, with `_raw` added. Anything cleaned or derived goes in a separate file next to the raw one, never over it.

Layout: `data/<category>/<original name>_raw.<extension>`, the category being what the data is. Add a row here in the same commit as the file. "Pulled" is the date of the downloaded file. Raw extracts of licensed data (WRDS, Bloomberg) go in `data/licensed/`, which is gitignored; commit the script that pulls them and the series derived from them instead.

Licences: all of this is for our coursework only. Several series are copyrighted by their source (marked below); cite them as given when we use them in the presentation or paper.
